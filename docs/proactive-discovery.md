# 猜你喜欢：发现值得试的改善

这份本地预览版让模型基于你明确选定的信息，提出可以尝试的改善办法。推荐附有资料依据；它是建议，尚未替你执行。

在首页专家的“我猜你可能需要”中选择参考资料，可以勾选当前工作区中的文本文件，或Finder中保存的具体方案。只选与这次分析有关的内容。所选正文会发送给Harness当前默认模型；这项授权不会开启集中回传。没有授权时不会分析正文或调用发现模型。

点击“开始找机会”后，模型会寻找0至3个有依据的机会，首页优先显示一个。证据不足时会如实说明，不用固定推荐补齐。建议不会凭空声称节省了多少时间，也不代表已经证明存在问题。

采纳“试试这个办法”后，Finder沿用原来的真实搜索与方案流程：能用现成能力就用或组合，有具体缺口再创建。在当前工作区完成结果，已有任务和未发送草稿保留。

“为什么推荐”可查看依据及即将查找的需求；无需为每个内部步骤点击下一步。“不相关”“这个我已经会了”会隐藏对应建议；“以后再说”最多暂停7天，材料变更时可以重新判断。低频的恢复入口可重新显示已处理建议。

可以随时通过“停止个性化”停用。停止会取消本次机会分析并清除当前推荐；已保存方案不因此删除。授权或材料变化后，旧建议不能被悄悄采纳到另一个工作区。停用设置保存失败时会明确说明，并在当前运行期间停止继续分析。

当前范围是用户选定的Finder需求/方案摘要及已登记工作区的指定文本文件。它不读取剪贴板、浏览记录、其他会话或全盘文件。文本检查会拒绝常见凭据和敏感路径，但不能识别任意秘密；不要选择不希望发给当前模型的内容。

发现阶段不安装插件、不修改资料、不发消息。采纳后的权限仍由宿主正常处理；搜索不全不能视为全市场没有供给。机会来源与采纳任务保存在独立本机记录中，衍生任务保持私有，不继承旧集中回传授权。
