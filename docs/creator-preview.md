# 一起创造 · 当前入口与历史验收

## 0.6.0-preview.1 的创作入口

先从首页查找现成方案。结果仍有缺口时，页面引导进入创作；已有可尝试方案时，也可主动选择按自己的流程定制。搜索来源失败会提示重试，不作为没有现成插件的证据。

进入后先看 DSH 插件能力、案例与首版实践，再点击「用我的需求起草」生成可编辑蓝图。引导页是本地说明，浏览不调用模型。案例区分别标明合成阅读列表的已验证范围，以及 Agent Twin 仅核对发行资产与文档的边界，不混用验证结论。

蓝图、澄清、供给重核、历史保存和官方 Creator 接续复用下述既有实现。Finder 负责准备需求和未发送草稿；开发仍交给官方 Creator。本次入口和界面验收另行记录，不能直接沿用下方 0.4 实跑作为 0.6 通过证据。

## 0.4.0-preview.1 的实现与实跑记录

本版将现成插件匹配接到官方 Creator。用户主动选择定制时，先评估配置、扩展或新建的最小路径；最多补三项影响首版的问题，允许明确记录假设。蓝图包含目标、流程、输入输出、界面、数据、工具权限、运行方式、首版范围和验收方法。

## 历史和草稿

旧 format-1 任务继续可读。共创保存成新的不可变版本，format-2 在每条任务内保存。普通会话关联和 Creator 关联分别存储；回看历史不会调用模型或重放会话草稿。编辑中的蓝图另保存在当前浏览器本地，回到同一任务版本可恢复。

Creator 的每次交接以任务、版本、内容哈希和工作区领取持久标识。已知会话 ID 必须先保存，再验证实际绑定、Creator 预设和工作区成员关系，最后才初始化未发送草稿。再次接续只打开已记录会话。若创建响应丢失且 ID 不明，只能标记未确定，不宣称跨进程绝对恰好一次，也不自动重建。

取消不会取消迟到结果的保存。关联保存失败保留精确会话 ID 和只重试保存的恢复入口。已有草稿或附件由宿主保留；Finder 不替用户发送、运行、安装或发布开发任务。

## 兼容和边界

官方能力依据固定于 deepseek-ai/deepseek-harness 提交 `687f282e8625c6b8d11ff58211a90524be2e4317`。已核验的 DSH `0.2.1-rc.2` 支持 `sessions.create({workspaceId, agentPreset: 'cordis'})`；`0.2.0-rc.2` 及未知版本采用复制蓝图后手动选择 Creator。代码与能力核查见本地研究记录，实际验收见 verification.md。

供给失败、没有读到 README、账号条件未知或尚未安装，不构成“没有插件”的证据。共创确认会按实质变化后的需求重新检索，保留范围、时间与未知项。共创内容及后续派生版本不进入集中摘要回传。
