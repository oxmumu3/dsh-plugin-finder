# 安装、首次使用与卸载

本说明对应 `@oxmumu3/dsh-plugin-finder@0.12.0-preview.1`。精确发布状态以 npm 与 GitHub Release 为准；尚未同步时保留当前安装，不用其他版本或本地路径冒充公开包。

正式发行记录见 [GitHub Releases](https://github.com/oxmumu3/dsh-plugin-finder/releases)。新版本附件及哈希确认存在前，不提供推测的下载地址。

## 兼容范围

| 项目 | 本版的准确目标 |
| --- | --- |
| 官方桌面与 Host | `0.2.1-rc.5` |
| Node.js | `^22.19.0 || >=24.0.0` |
| 四个官方 SDK peer | 下列包均为 `0.2.1-rc.5` |
| 其他 RC、next 或 alpha | 未由本版声明支持，不能从安装成功推导兼容 |

四个固定 SDK 为 `@deepseek-ai/dsh-app-boot`、`@deepseek-ai/dsh-storage-domain`、`@deepseek-ai/dsh-tools`、`@deepseek-ai/dsh-sandbox`。宿主提供这些 SDK，不需要用户另外安装不匹配版本。

必须先完成最终包声明、内部版本检查与接口回归，以及真实官方隔离 Host 的安装、启用、卸载/重启验证，才能确认本版兼容完成。当前步骤仍在本轮验收中，不沿用旧 rc.2/rc.3 的结果。

## 安装或更新 Finder

公开发布并回读精确 npm 版本后，在正在使用的官方 Harness 原生「插件 → 添加插件」中填入：

```text
@oxmumu3/dsh-plugin-finder@0.12.0-preview.1
```

这是本版的精确 npm 安装身份。若注册表尚未返回该版本，请查看正式 Release 并保留当前安装。通过本地 TGZ 安装时，应核对发行哈希；绝对路径必须位于目标宿主机器，不能使用另一台机器的路径。

按宿主提示核对包名、兼容诊断与实际版本，安装并启用后打开侧栏「发现好插件」。Desktop 与终端同名 `dsh` 可能来自不同安装，优先使用当前应用的原生插件页。安装是针对实际 profile，不要为更新日常插件另建无关 profile。

如安装清单中已有旧的 unscoped `dsh-plugin-finder`，先核对来源、实际版本与启用状态，保持同一 Finder 只有一份启用。不要同时启用两份相同入口，也不要为改包名清除历史、领域存储或会话草稿。重要记录可先从「历史方案」导出备份；版本号本身不能证明覆盖了另一条私有修复线。

## 第一次使用

- **描述需求，点「帮我找方案」。** Finder 连续理解目标、核对来源并组织方案。原生能力足够时不增加插件。
- **现成方案合适，点「使用这个方案」。** 一个插件或 2–4 个插件组合由 Finder 自动首次安装、启用并回读实际加载状态，之后在当前工作区执行原任务，无需另进插件管理器。
- **只有部分能力缺失，点「补齐并使用」。** 保留 1–4 个计划复用的插件，只创建列出的缺失能力；没有真实必答缺项时自动接续，有缺项或权限要求时在原上下文处理。
- **主动定制。** 可以选择「创建自己的插件」，沿用需求并查看范围；关键输入补齐后在当前工作区开始创建。

任务目标优先沿用当前会话的工作区或唯一可靠目标；无法可靠判断时才选择。安装影响当前 profile，不是每工作区一份沙箱。已有冲突版本、来源无法确认、需重启或额外构建许可时保留真实状态，不静默替换、不提前执行。恢复旧任务只观察原关联，不自动重装或重发。

首页建议未授权时显示明确标注的通用想法或本机线索。自愿开启最近方案建议后，最多三份 Finder 需求与目标、产出、约束摘要交给当前模型，不因此读取其他文件。需要自选材料时再打开参考信息；已有授权在原范围内复用，可以停止。

## 卡点与恢复

| 现象 | 应如何处理 |
| --- | --- |
| 未出现入口或仍是旧版 | 核对当前 profile 的实际安装、启用版本与加载诊断，不能用另一 profile 的状态代替。 |
| 未配置模型 | 配置宿主默认模型，再重新读取配置；目录浏览本身不依赖模型。 |
| 搜索来源失败或覆盖不足 | 保留需求并核对来源后重试，不把未知当成没有供给。 |
| 版本或来源冲突 | 保留现有插件并显示差异，不自动降级或覆盖。 |
| 安装结果未知、需审批或重启 | 观察同一次记录并按官方提示处理，不盲目重复安装。 |
| 旧执行工作区/会话不可用 | 保留原关联并核对目标，不用新建会话冒充恢复。 |
| 会话结束但产物不符合目标 | 依据实际产物继续修改；运行结束不等于需求验收。 |

## 停用与卸载

在当前 Harness 原生插件页找到实际包 `@oxmumu3/dsh-plugin-finder`，按宿主提示停用或卸载。旧 unscoped 包需按其真实包名分别核对，不机械替换。

停用或卸载不表示本机历史已经删除。不要手动清空 `plugin_finder_history`、草稿或关联源码目录。卸载也不代替集中记录删除；若曾自愿回传摘要，删除以服务端确认结果为准，详见[数据回传说明](data-sharing.md)。
