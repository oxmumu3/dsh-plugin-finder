# 从需求到方案 · 本地预览 0.6.0-preview.1

首页从「你想完成什么？」开始。写下任务，点击「帮我找方案」，Finder 依次理解目标、材料和约束，搜索可用来源，再给出可检查的方案。无需先知道插件名字，也不用在多个功能标签间选择。

## 首页

需求输入是主入口；猜你喜欢与精选插件就在下方。猜你喜欢只来自明确兴趣或本机已保存方案中的正向线索，附推荐理由；没有线索时直接展示四组精选。兴趣选择、减少推荐和恢复推荐放在默认折叠的「调整推荐」里。

点开精选可查看用途、前提、版本、来源与验证范围，再从「试试这个场景」准备自己的需求。准备场景不调用模型；实际查找由「帮我找方案」发起。预览与私有条目不提供未经核对的安装入口，公开固定版本仍受原有来源和时间门禁约束。

页头只保留次要的「历史方案」与「更多」入口；「历史方案」打开「我的方案」列表。重新打开插件先显示首页，已有方案和蓝图可继续；旧工作不占据新的需求输入区。

## 查找与调整

一次点击连续执行需求理解和推荐，通常仍会有两次宿主模型请求，沿用既有额度。页面显示当前进度，可以取消；请求失败时保留需求并提供重试，取消后不再继续下一阶段。

结果首先呈现最小方案、重要前提、安装和会话接续。理解字段、候选作者资料和来源覆盖按需展开，需要时可修改理解并重新搜索。部分来源失败会说明覆盖不完整；全部来源不可用时呈现搜索错误，不把错误写成「没有插件」。

候选安装仍交给 DSH 原生插件管理器。选择明确的工作区后，Finder 准备未发送草稿，由用户核对材料并发送；已有草稿和附件由宿主保留。

## 结果不合适时，再进入创作

现成方案仍有缺口，或希望按自己的流程定制时，先进入创作引导。这里回答三个问题：DSH 插件能做什么、已有例子验证到了哪一步、怎样把首版限定为可检查的一条流程。

- 能力说明覆盖侧栏工作台、专用 Agent 工具、本机状态和获授权的外部服务连接，标明已核查的宿主版本。
- 阅读列表案例是已实跑的合成样例，说明元信息保存、筛选、只读预览与刷新读回的范围；目录选择器、重启恢复和长期稳定性不据此宣称通过。
- Agent Twin 案例引用已核对的预发布资产与文档，不能用资产核对代替真实通道或业务执行验收。
- 首版实践先限定一个任务、明确权限和数据范围，再约定能检查的输入到结果路径。

浏览引导不调用模型。点击「用我的需求起草」后，沿用既有共创服务评估配置、扩展或新建，生成澄清和可编辑蓝图。确认时按变化后的需求重新核对供给，再由官方 Creator 继续开发。Finder 保留草稿与会话关联；建造、安装和发布仍是后续明确动作。

## 历史、草稿与验证

已有任务、不可变版本、主动反馈与会话关联继续保存在本机。「我的方案」可回看历史并恢复保留的输入；首页不列出全部草稿。开始新任务或切换场景前先可靠保存旧编辑，保存失败时保留当前内容。恢复仍核对精确任务、版本和蓝图内容哈希，移除输入副本不删除历史任务。
