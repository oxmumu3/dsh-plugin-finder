# 首页精选与猜你喜欢 · 本地预览 0.6.0-preview.1

无需先描述需求，在首页输入框下即可浏览 AI 分身、微信家庭助手、DSH Dot 与 Dot 连接 Harness。没有独立「精选」功能标签。主插件、桥接与管理组件按产品归组；OpenAI Dot 和 DeepSeek Harness 在使用前提中列为平台依赖。

首批为作者牛村木木山的自研策展。卡片分别说明场景、适用人群、推荐原因、前提、限制、组件、版本、资料核对时间与来源。Agent Twin 的固定公开预发布资产经过下载、包信息与校验值核对；其余三组仅展示本地预览或私有接入说明。本次资产核对不等于功能验收，预览卡不提供公开安装入口。

## 猜你喜欢

展开「调整推荐」后可选择 AI 分身、家庭助手、项目协作或工具连接兴趣；也可使用 Finder 内已有方案线索，获得最多三个解释明确的推荐。没有线索时展示精选，不生成个性化说辞；部分完成、受阻或未知结果不贡献正向历史信号。相关性来自有限关键词规则，不能推断长期偏好或保证适用。

兴趣和隐藏条目只在当前 DSH 的本机浏览器存储；不新增遥测，不读取其他会话或文件，不调用模型。可取消兴趣、标记不感兴趣或恢复全部推荐；隐藏仅作用于个性化推荐，精选仍可浏览。存储失败时标明当前窗口有效。

## 从场景到自己的需求

「试试这个场景」先保留当前输入和未保存编辑，再通过原有服务确认开始新需求。失败时原内容仍保留；可以重试。原任务和版本仍在「我的方案」，保留的编辑草稿在「我的方案」中恢复或移除，首页不展开草稿列表。

每份输入关联原任务与版本；恢复原方案时核对精确身份，未保存蓝图仅在内容哈希对应时恢复。输入副本最多 20 份；满额或无法可靠写入时停止切换，不自动删除旧副本。移除输入副本不删除历史任务。目录场景草稿保持可编辑，由你点击「帮我找方案」后才连续调用理解和推荐流程；匹配、普通会话与官方 Creator 继续使用既有路径。

公开安装地址只支持固定版本的 GitHub Release 或 npm tarball，核对时间最长 30 天；到期保留说明并暂停复制入口。安装交给 DSH 原生插件管理器。
