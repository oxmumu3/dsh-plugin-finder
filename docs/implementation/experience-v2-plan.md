## 交付目标

把已研究的 V2 视觉与动线落到真实 Finder：需求首页、去重的精选/推荐、持续对话与版本化方案、可逐块修改的蓝图、精确版本的官方 Creator 接续。历史 HTML、任务、编辑草稿和 Creator 恢复机制保留。仅本机实现与验收，不发布公共 Release。

## 实现顺序与职责

1. 保留现有服务和数据格式。推荐继续用真实 refine → recommend；新增自然语言蓝图修订入口，投影已有版本祖先链为对话，不复制另一套聊天存储。
2. 独立体验组件负责首页、对话、成果与蓝图；沿用 Host 主题别名并提供浅色回退，窄屏堆叠。来源、安装、工作区、历史和反馈组件继续使用现有真实控制器。
3. 控制器接通连续调整，按任务/版本保存未发送输入；取消、超时、断连保留输入，晚到结果不可覆盖新任务。普通方案调整与蓝图调整分别绑定对应接口。
4. 单元与集成回归覆盖旧数据恢复、祖先链、真实模型调用边界、局部编辑保留、异步取消和两条接续路径。生产构建通过后检查桌面、窄屏、深色、键盘交互。
5. 只读检查原生运行状态，再决定安全的本地更新。先备份真实历史与草稿；不得重启或覆盖其他活跃任务。实际使用已登记的测试工作区走匹配和 Creator 两条路径，并记录模型、服务、Host/UI 各自证据。
6. 独立规格与代码审查，修复后打包，记录包校验、实际验证范围和待办，局部提交并回合并主项目。

## 验收边界

- 首页只保留一个需求入口；推荐与精选不重复列同一产品，无虚构兴趣或认证。
- 输入后自动理解与查找；进一步描述在同一任务追加新版本，不让用户重复填写需求字段。
- 搜索失败、过期缓存及覆盖不足显示为证据限制，不宣称生态没有插件。
- 蓝图由模型整理，可读后逐块编辑；澄清按一个关键问题推进，自然语言修改必须实际调用宿主模型。
- Creator 接续只准备并保留精确版本的未发送草稿；生成、安装、任务验收分别记录，不混称完成。
- 不覆盖既有草稿，不删除历史，不触碰微信客户端或当前代理链路。
- 页面可用与视觉检查不替代真实原生验收；实际无法执行的步骤列出具体阻塞。
