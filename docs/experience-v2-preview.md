# V2 体验预览 · 0.7.0-preview.1

本版为本机候选，尚未公开发布。旧版包、HTML、任务和草稿继续保留。

## 从需求到方案

首页保留一个需求入口。三个例子可以填入再修改；替换前保留已有未发送输入。精选与有依据的推荐合在同一个集合，同一产品只出现一次。只有明确兴趣或本机历史提供线索时才显示推荐理由。

输入后连续理解与查找，结果页并排保留对话和方案。补充材料或限制后，会真实调用宿主模型，并在同一任务生成新版本。原方案可回看。查找失败时保留输入和上一版结果，重新打开也能接着重试，避免重复提交已保存的调整。

推荐先解释为什么、关键前提和如何继续。候选来源、安装说明、完整草稿、反馈与历史按需要展开。来源失败、过期或未知不表示生态没有插件；此时优先显示覆盖不足和重试入口。

## 从方案到自己的插件

现成方案有缺口，或希望按自己的流程定制，都可进入共创。先看能力和案例，再用原需求起草。蓝图按目标、使用流程、数据权限和验收分块呈现；每块可以编辑，不再要求一次填写全部字段。澄清一次展示一个尚未回答的关键问题，也可直接在对话里说明。

自然语言修改使用真实模型，连同当前手工编辑一起处理；模型修改前的编辑仍留在来源版本。新的明确限制累积进入保护集合。确认蓝图后才重新检索供给，选择实际工作区，将精确版本的草稿接续到官方 Creator。接续成功、模型生成、安装与任务验收是各自独立的状态。Finder 不自动发送或发布。

## 保留与兼容

- 版本祖先链投影为对话，不迁移或另建重复聊天数据库。
- 历史任务、旧编辑草稿、普通会话和 Creator 关联继续兼容。
- 新输入、取消、超时、失败重试与旧版本切换均有保护。
- 同一 Host 侧栏入口；主面板使用 Host 主题，窄屏改为上下布局。
- 共创与其后续反馈只存本机。普通匹配的可选摘要回传仍默认关闭。

具体自动回归、隔离官方 Host 与共享 Desktop 的验收状态见本轮交付记录；本说明本身不代表实装或运行已通过。
