# 首页信息层级修订

用户反馈：界面仍然堆成一团，易读性、层级与品质感未达到要求。本轮在已经授权的单工作区动线内调整界面，不重新访谈或增加流程。

方向：克制的工具工作台。用白色画布、统一阅读轴、清楚的字阶和段落间距区分任务与浏览；少量语义图标仅帮助识别产品。
画布：宿主主题的 base / layer-1；离线默认 #ffffff / #f5f6f8。
文字：#202730 主文、#606b78 次文；操作沿用 #245dd8。运行时均服从宿主语义变量。
字体：宿主系统中文无衬线；页面标题40/32、章节22、产品17、正文14–16、元信息12–13px。
布局：需求输入为主、单条推荐为辅，底边对齐；浏览区以独立段落开始。精选四列短条目，窄窗两列、手机一列。分类继续保留六类各三个，原地查看全部。
动效：仅焦点与主动操作反馈；尊重减少动效。
不采用：重复解释、卡片内套卡片、装饰渐变、全屏大留白或新增tab。

取舍：只加间距无法解决内容重复；改为纯搜索页会丢掉用户要求的主动推荐与分类浏览。采用保留原功能、降低首页文字密度的方案。长介绍留在原有详情，不新增点击中转；状态、推荐依据、权限和失败提示保留。

检验：实际截图检查宽窄窗口、完整目录、长输入/恢复任务、有依据推荐、明暗主题；回归原有输入保护、动作、详情与目录处理器。视觉喜好仍以用户反馈为准，不以代理走查等同用户认可。
