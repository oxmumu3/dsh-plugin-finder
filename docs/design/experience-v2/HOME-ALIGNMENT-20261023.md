# 首页双列对齐修正

2026-10-23。用户指出“你想完成什么”在卡外，而“猜你喜欢”在卡内；两按钮大小和上下位置也不一致。用户同时明确精选插件和插件商店已经可以，本轮不改这些区块。

原问题是左右用了不同的结构，仅靠两块整体底部对齐，无法让标题、卡片和动作逐层对齐。本轮把左右改成相同的三层：外部标题、外部说明、内容卡片。两列共享标题/说明/卡片的网格行；卡片随实际内容自然增长。统一内边距、圆角和按钮尺寸，保留主次颜色及现有调用。

具体实现：两语义区块使用 CSS subgrid 共享行；表单和推荐内容分别为 flex column，操作 footer 留在底部。两主按钮统一 132×44px，同样靠右、距离卡片底部20px。推荐理由、已选插件栏和可手动扩高的 textarea 都在正常文档流中。窄屏恢复完整左块→示例/提示→完整右块的阅读顺序。

验证：

- 42项现有体验与HTML制品测试通过；生产构建、diff检查通过。没有为样式数字另写镜像单测。
- Ego194、1280默认场景、1280/960个性化推荐：标题顶部差、卡片顶部/底部差、按钮顶部/底部差均为0px；两按钮均132×44px。
- 长插件名选择后同样对齐；将textarea高度设为360px模拟用户扩高，卡片共同增至533px，按钮差仍为0px。
- 390px及1280窗口内700px面板正确单列；按钮同宽高、相同右侧内边距，无横向溢出。
- 独立审读实看四张截图与测量文件，对用户限定两点未发现剩余错误。不是对整体设计的用户验收结论。
