# 插件商店入口修正

用户指出最新页面像把应用商店砍掉。核对b58717e与c8d3d47：6,563条、六类×3、完整列表、搜索、分页和接入方案的动作均在；但精选增加行数、插件名降成小字、商店缺少显式入口，造成真实的可发现性退步。不能以“代码还在”否定用户观察。

本轮限定修正：

- 首页示例旁显示“逛逛插件商店”，页内直达原商店区，不增加tab、不改变用户输入。
- 区域明确命名“插件商店”，显示收录条目数及“浏览全部插件”，直接复用全量浏览。
- 条目恢复真实插件名称为标题，用途紧接其后，作者与使用前提保留。
- 精选、商店两块继续独立；不移除既有分类、搜索、分页或使用/创建流程。

验证：45项相关测试通过，生产bundle构建成功，diff检查通过。Ego186实点首屏锚点、全量入口（6,563条/274页/每页24条）、Zotero搜索（全目录6条）、返回（6类×3）、原需求不变；390px窄屏无横向溢出。未调用模型或更改Desktop安装。浏览器第一次href相对选择器匹配失败，观察真实锚点后用其CSS选择器正常点击，产品链接本身可用。

当前HTML与共用前端均更新；修正前HTML及截图保存在output/dsh-plugin-finder-store-entry-2026-10-23。当前package版本仍为preview.7，不用这个未递增的字符串区分设计候选；具体构建通过build-receipt.json校验。本轮没有发布新安装包或公开Release。
