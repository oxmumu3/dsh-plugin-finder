## Mock 与真实检索

`preview-controller.mjs` 的会议待办示例固定为 `gap`，其他预设覆盖 native/combo；它通过定时状态切换演示界面，既不查模型也不证明市场没有相应插件。任意自由输入保留并提示演示范围；目录选择也明确未分析/安装。

真实入口 `client.js` 调用 newRequest → analyze → recommend；`service.js` 正常路径先 discovery.search，再让模型判定 native/single/combo/gap。全部来源失败会报错，不继续当成无匹配。明确禁止安装时可跳过插件搜索；点名某插件是定向核对；用户也可在已有方案后主动选择定制。这些情况都不表示搜索了整个市场。

发现并修复一处语义缺口：来源 live 但候选未读完、作者资料超时/无法解析或免 Key 前提未知时，界面此前未识别不完整覆盖。现在 `experienceSourceHealth` 将其作为待核对，gap 主动作是重试，保留明确主动创建；已匹配方案仍可使用。创建前仍有原有的蓝图供给复查。本修正增加三条有效边界回归，不把有限检索说成完整市场证明。
