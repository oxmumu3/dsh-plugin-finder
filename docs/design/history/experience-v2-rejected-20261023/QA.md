# Finder V2 原型走查

2026-10-23。交付文件为 [index.html](index.html)，73,938 bytes，SHA256 `74043906f680573603f26811cf0b1232551c7b3daf7efcdfeadf7030d1927947`。

这是**离线有界交互原型**。本轮验证了页面、脚本和指定演示状态；没有调用真实模型、搜索、安装、工作区、官方Creator或微信，没有真实参与者的可用性测试。第一眼是否符合用户期待，仍待本人审阅；不能把代理视觉检查说成用户认可或效率提升。

## 实际检查

浏览器使用ego v2的同一个Space 113。实际观察如下：

| 任务 | 观察到的结果 |
|---|---|
| 冷启动首页 | 无兴趣/历史时为“编辑精选”；四个产品各出现一次。单一需求输入与主动作；不增加功能tab。 |
| 有依据的推荐 | 选择“家庭日常”后家庭助手提前，理由明确引用本次演示选择；其余三条保留且不重复。没有读取真实画像。 |
| 探索与开始 | 家庭助手详情显示价值、前提、策展快照版本与非实时边界；准备场景只预填可编辑需求，不触发搜索。Escape返回原详情按钮。 |
| 草稿保护 | 先输入鱼缸纪录片想法再点会议示例，旧输入在“未提交的想法”可恢复；会议示例不再因“原文出处”误分为阅读。 |
| 查找与取消 | 原请求保留；取消后为“查找已经停止”；迟到演示未将它变回成功。取消记录仍在历史。 |
| 同一结果修改 | 原阅读需求保持不变；补充只读、仅阅读状态后，方案和版本更新。否定句“我不想只做阅读状态”只保留原话，不冒认修改。 |
| 主动共创 | 已有方案可“在此基础上定制”；只询问首版使用范围。未知回答“明年春天再说”没有生成蓝图，仍待确认。回答按钮只有一组。 |
| 可读蓝图与局部编辑 | 蓝图有范围、输入/产出、数据/权限、验收四块；编辑关闭后可继续，应用后同一蓝图更新到v5，旧版本仍可查看。 |
| Creator预览 | 选择虚构的“独立测试”工作区，生成原需求+蓝图v5交接材料；明确没有创建真实会话、发送或安装。 |
| 失败恢复 | 部分来源未返回时显示暂定建议；警告持续到共创和蓝图。重新查找后警告消失，蓝图保留；不称为市场无供给。 |
| 未包含的自由输入 | 鱼缸纪录片显示没有对应演示，原话保留，没有套入阅读方案。 |
| 历史与未提交补充 | 离开后恢复v5蓝图，已改范围与“这句先不发送”仍保留。版本弹窗显示先前范围与蓝图记录。 |
| 390×844 | 首页、方案、蓝图和材料弹窗无横向溢出；“查看方案/蓝图”跳到成果顶端约20px，“回到对话”跳回对话约20px。 |
| 键盘及触点抽查 | Escape关闭详情/编辑/版本弹窗；返回原触发按钮，输入聚焦可见。390首页按钮没有低于24×24 CSSpx的命中区域。没有做完整读屏或全产品焦点循环审核。 |

## 静态与状态验证

- `node --check` 校验内联脚本通过；无远程src/href依赖，无运行时CDN、字体加载或真实服务请求。
- 独立静态挑错发现并修正：会议误分类、首页草稿覆盖、否定句误改、澄清冒认、跨任务重试卡等待、来源警告在共创中丢失、弹窗内部换页的焦点恢复问题。
- Node VM定向状态演练通过上述分支及产品去重、两次修正、局部编辑、交接预览、取消/迟到回执、来源重试。DOM stub不是浏览器或服务测试；浏览器检查另列在上表。
- 新HTML没有旧自有GitHub namespace。第三方研究链接保留实际canonical来源；未发布或push。
- 未更改生产src、package、dist或真实运行数据，因此不重跑与本轮无关的407项生产测试，也不沿用它们宣称新UI已原生通过。

文本token计算对比：深色正文对白13.73:1、辅助文字对浅灰5.57:1、行动蓝对白5.78:1，对柔蓝5.05:1。仅计算指定颜色组合，不代表所有占位文字、禁用态、控件边界或完整WCAG合规。

## 正式实现前仍需核对

把这个设计接到生产前端时，需映射真实模型和检索事件、任务/版本持久化、候选重新评估、草稿保护与精确Creator恢复；不能复制演示白名单当模型理解。还需核对宿主主题、真实内容规模和更完整的辅助技术行为，再分别做实际服务与用户验收。

当前自由修正只覆盖少量阅读示例；其他场景的补充提示和可修改范围在正式实现中应按实际任务细分，不能用同一套阅读提示承诺所有任务都能修改。
