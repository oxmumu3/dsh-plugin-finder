# 0.10.0-preview.6：官方 rc.4 / rc.5 兼容维护

保留已支持的 0.2.0-rc.2、0.2.1-rc.2、0.2.1-rc.3，新增明确验收的 0.2.1-rc.4 / rc.5。0.2.0-rc.2 仍为搜索与历史路径，执行和 Creator 从 0.2.1-rc.2 起可用。

本次只调整 Host/SDK 兼容声明、客户端执行与 Creator 的准确版本门槛，并由源码重建客户端。历史、草稿、授权、数据格式、默认模型和第三方插件选择逻辑沿用原实现。安装通过和合成 Host 验收，不等于真实账号、真实模型任务或收件验收。

维护者先运行 `node scripts/compatibility.mjs --matrix` 核对声明，再运行 `npm run compatibility:check` 读取官方 npm latest。未经验证的新官方 SDK 会使检查失败；须先完成对应 SDK 回归、真实官方 Host 安装与激活验收，再更新 `compatibility.json` 和准确版本声明。
