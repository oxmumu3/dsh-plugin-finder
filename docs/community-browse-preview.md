# 分类浏览 · 公开预览版

本次发布版本 `0.9.0-preview.10`，2026-10-24；[固定版本 Release](https://github.com/oxmumu3/dsh-plugin-finder/releases/tag/v0.9.0-preview.10)与附件，安装见[安装说明](install.md)。

首页仍以需求输入为主，右侧一个可开始的场景，下面是作者精选。精选再往下增加「按用途找插件」：六类、每类三个。点「查看全部」在原区块展开，支持类别筛选、名称/作者/用途搜索及24条分页；返回分类不改动用户原输入。

「查看使用方案」表示核对所选插件的来源、能力和前提，随后接回本页的使用流程。浏览不调用模型；生成方案沿用宿主模型。精确来源随方案和历史保存，用户编辑时继续沿用，首页可明确取消指定；不能仅靠自然语言插件名称猜对象。用户点击「使用这个方案」后，Finder 才自动安装、启用精确所选插件并在当前工作区执行；额外许可仍由宿主处理，不将目录收录当成安装、兼容或运行成功。

## 本地HTML与真实宿主

[HTML](design/experience-v2/index.html)与生产组件共用分类数据和视图，可离线浏览完整快照。任意目录条目的真实分析需要 Harness；HTML不会把点击任意条目伪装成已查证、已安装或已创建。原有几个示例的演示结果仍明确标为合成。

0.8 的原生只读、现成插件、官方 Creator 与恢复验收保留在原报告中，不用来冒充新目录路径的验证。preview.8 在现用 Desktop 完成指定创建场景；本轮以真实检索到的 `dsh-tool-qrcode@1.0.0` 验证未安装插件的自动安装、启用、工具调用和 SVG 产出，独立解码符合输入网址。首次执行在 preview.9 完成，preview.10 通过同一任务刷新恢复、不重复安装或执行；全套回归 651 项通过。这只证明已测场景，不表示目录内插件均经过兼容或功能验收。

## 生态思考的边界

社区已经有分类网站、插件市场和对话搜索工具，官方也有对话 Creator 与配置组合能力。本项目在验证从表达目标到匹配、使用、必要时创建的连续体验，而非声称发明了这些能力。用户规模的绝对数字、重复功能率、普通用户需求覆盖和长尾贡献占比均不能由目录数量推导。研究与作者思考保留在 `docs/research/ecosystem-20261023/`。

创建后让作者选择公开、再供其他人使用，是后续方向；本版没有投稿池、自动公开或代作者发布。
