# 0.12 真实演示与验证范围

作者：牛村木木山

本版围绕同一个目标：先复用已经合适的插件，只创造仍然缺少的能力，再继续完成原任务。首页保留目标输入、基于授权上下文的建议、精选插件和分类商店；混合方案明确列出复用与待补齐部分，主操作直接推进工作区执行。

## 两个合成场景

- **主 Agent 调用 Finder**：用户只交代跑步手账目标，Agent 经 Finder 首次安装现成配速及单位换算插件，创建缺失的记录与界面。经历有界审查修正后，原任务完成。最终界面读回两条记录、7 km、42 分钟；添加及刷新保留也已实际操作。该样例最初在较早候选完成，本版进行了当前界面读回，不能称本版从零重做。
- **用户从 Finder 发起**：真实搜索返回可复用的单位换算能力，混合方案只补尺寸记录的新增、编辑、删除、存储及界面。官方 Creator 在同一工作区完成源码并通过宿主首次安装；一次首用会话关联修正后，实际新增 7.5 cm 得到 75 mm，编辑 8.25 cm 得到 82.5 mm，整页刷新和切换页面保留，最后删除测试行，原 1200 mm 和 2500 mm 两条记录保持不变。

首次安装遵循宿主审批；验收保留失败和修正记录，不表示任意第三方组合都能一次完成。两个生成样例只在私有合成工作区保留，不作为公开插件发行，也不随 Finder 预装。
