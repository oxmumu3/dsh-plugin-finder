# 发现好插件 0.12 真实界面图

作者：牛村木木山

先查现成能力，只创造缺失部分，在当前工作区做到能用。

这四张是实际官方 Harness 0.2.1-rc.5 上的运行界面。素材全部为合成演示资料，不含私人项目内容。生成的两个样例不随 Finder 预装，也不公开发布。首次安装遵循宿主审批。

- **01-home.png**：首页：同一位插件专家，接目标，也给有依据的建议。 当前 C8 真实首页；输入框为同一合成尺寸任务的未发送简述。右侧是已授权最近一条合成方案摘要后，真实模型生成并缓存的建议，未采纳执行。
- **02-hybrid-plan.png**：方案：保留现成换算，只补记录能力。 当前 C8 只读打开同一任务的历史版本 2；沿用当时真实搜索结果，没有重新搜索或重发创建。候选覆盖不完整的提示原样保留。
- **03-created-size-book.png**：成果：尺寸对照本，换算继续复用 convert。 当前 C8 官方隔离 Host，Creator 生成的私有样例已首次安装并经过一次会话关联修正；新增、编辑、刷新、切换与删除实测通过。截图恢复为原两条合成记录。
- **04-agent-running-journal.png**：成果：主 Agent 复用配速与换算，只创建手账。 样例在早期候选完成创建、首次安装和操作验证；当前 C8 实界面读回 7 km、42 分钟、2 条记录。不是 C8 从零重新生成的证据。

图片保留原始 PNG；适合直接用于展示产品界面。`manifest.json` 记录捕获时间、尺寸与哈希。新版公开发布、市场收录与日常安装分别以发行回执为准。
