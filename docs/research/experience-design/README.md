## 本轮最重要的三项改变

1. 首页帮助形成需求并探索用途：输入和策展在一个页面，不按新增功能继续加tab。
2. 对话接到持续可改的成果：推荐理由、关键前提、下一步可直接看见；补充回到同一个方案和版本。
3. 将未知与恢复纳入产品：冷启动不装作个性化，来源失败不装作无供给，原型不装作模型、安装或Creator已接通。

旧版 HTML 与原生运行记录完整保留。本轮只新增研究、方法和独立原型；生产源码、已安装版本、真实任务与草稿不因本次设计研究改变。
