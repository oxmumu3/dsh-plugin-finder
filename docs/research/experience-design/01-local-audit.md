## 七项具体缺陷、改造影响与验收

### 1. 首次输入缺少可用的脚手架

- **当前证据 / 已实现：** 首页只有问题、通用说明、单一文本域、一个 placeholder 与提交按钮；没有直接可点的需求示例或输入帮助。[client.js 第 968–978 行](../../../src/client.js#L968)
- **用户成本：** 虽然不再要求先填结构化字段，用户仍需独自想清楚怎样描述任务；精选卡没有直接解释自己与这个输入的关系。
- **新流程影响 / 待实现：** 保留自然语言主入口，提供少量具体场景示例作为可编辑起点。提交后沿用原话，用户可以再补一句修正；不把示例变成开始使用前必须分类的问卷。
- **可验证验收：** 空输入时可直接发现并点选示例；点选后能修改、撤回，不调用模型、不覆盖原任务。带已有输入切换场景，原输入必须可恢复；真正查找只在明确提交后发生。

### 2. “猜你喜欢”与精选重复占用首页

- **当前证据 / 已实现：** 推荐区域渲染推荐项后，精选区域继续 `featuredCatalog.map` 全量渲染；同一产品可出现两次。[featured-view.js 第 90–96 行](../../../src/featured-view.js#L90)；推荐最多三项见 [featured.js 第 63–80 行的 `rankFeatured`](../../../src/featured.js#L63)。
- **用户成本：** 页面看起来更长，但并未提供更多选择；用户需要辨认这些是不是不同方案。
- **新流程影响 / 待实现：** 使用一个去重的场景集合。有可靠兴趣信号时把理由加在对应卡片上；冷启动直接展示策展内容，不伪装成个性化推荐。
- **可验证验收：** 无兴趣、有兴趣、有本机历史三种状态均检查产品 ID 去重；清除或减少推荐后结果可解释且可恢复；不新增读取其他会话或远端画像的行为。

### 3. 不同可用状态的卡片几乎等权

- **当前证据 / 已实现：** 卡片统一为标题、摘要、状态和“查看详情”；公开包、本地预览、私有接入共用一个框架，状态只是一行标签。[featured-view.js 第 6、31–42 行](../../../src/featured-view.js#L31)
- **用户成本：** 用户必须再进详情，才能知道可以尝试、需要维护服务，还是只能了解设计。相同按钮没有表达不同下一步。
- **新流程影响 / 待实现：** 卡片直接回答“能得到什么、使用前提、现在能做什么”。公开可核对包、预览案例、私有接入分别使用准确动作；不让边界说明压过任务价值，也不把公开包核对写成功能通过。
- **可验证验收：** 三种状态和失效来源分别有明确文字与动作；预览/私有条目没有虚假安装按钮。来源过期或不合规时停止提供复制入口，但保留说明和可编辑场景入口。仅凭颜色不能区分状态。

### 4. 搜索等待时丢失任务上下文

- **当前证据 / 已实现：** 首页搜索串行执行 reset、理解、推荐；搜索期间工作内容和任务历史被隐藏。主要反馈是全局 spinner 文案，`showFeatured` 在 operation 期间拒绝切换。[client.js 第 365–380、644–647、1039–1040 行](../../../src/client.js#L365)；推荐超时上限 300 秒见 [第 163 行](../../../src/client.js#L163)。
- **用户成本：** 可能等待数分钟，却无法稳定看到“正在处理哪句话、已完成哪一步、取消后会怎样”。
- **新流程影响 / 待实现：** 原请求和上一份已保存结果保持可见，按真实状态显示理解与查找阶段。取消保留已填写内容。若允许等待时浏览无副作用内容，需要调整当前单 operation 对导航的限制。
- **可验证验收：** 理解、检索、取消、超时分别有状态与恢复动作；取消不进入下一阶段，迟到回执不覆盖新输入。没有真实进度接口就不显示百分比、已读来源数或假进度。浏览能力未实现前，原型必须标记模拟。

### 5. 结果页缺少围绕下一步的层级

- **当前证据 / 已实现：** 页面先排方案步骤、限制、共创入口、完整安装指引，之后才到工作区与会话接续；候选、供给统计、反馈继续在同一长页出现。[client.js 第 983–1005 行](../../../src/client.js#L983)
- **用户成本：** 建议、前提、安装、执行准备和试用反馈互相争夺注意力；用户得先读长流程，再判断此刻该点哪里。
- **新流程影响 / 待实现：** 结果顶部提供一句判断、关键前提与唯一主动作；步骤、其他候选、证据逐层展开。需要安装时进入有上下文的安装引导，接续时才选择实际工作区。试用反馈随任务返回，不在尚未尝试时占据主流程。
- **可验证验收：** 在 1440×1000 与 390×844 视口，首次结果视图能看出推荐路径及下一步，不必先滚过完整安装说明；键盘能到达主动作。`native/single/combo/gap` 四类结果都保留准确前提，展开/收起不丢任务状态。

### 6. 其他候选缺少通向选择的动作

- **当前证据 / 已实现：** 候选卡提供证据、来源、版本与安装操作，没有“以此调整方案”或可操作的方案比较；选中集合由 `plan.pluginIds` 决定。[client.js 第 810–811、927–950、966–967 行](../../../src/client.js#L927)
- **用户成本：** 用户读到更适合自己的候选后，只能回头修改需求或自行复制资料；比较信息没有接回核心流程。
- **新流程影响 / 待实现：** 提供“用这个重新评估方案”或有明确差异的比较入口。重新规划需保留原请求和原版本，并核对所选候选与约束；不能只在前端换一个“方案中”标签。
- **可验证验收：** 候选版本、权限或运行前提不同会显露在比较中；重新规划生成新的可追溯版本，原方案仍可回看。该选择动作目前未实现，原型不能把它画成已调用真实规划接口。

### 7. 共创重新变成大型编辑表单

- **当前证据 / 已实现：** 蓝图 11 个字段全部展开为 textarea，另有假设与澄清回答。起草前引导页又串起能力说明、案例、实践，主起草按钮靠后。[client.js 第 1008–1025 行](../../../src/client.js#L1008)、[creation-guide.js 第 29–83 行](../../../src/creation-guide.js#L29)
- **用户成本：** AI 生成的信息仍以逐项填写/审阅的工作交还给用户；单纯删减文字不会改变流程负担。
- **新流程影响 / 待实现：** 在同一需求上下文中持续补充和修正；蓝图默认以可读卡片呈现，按块展开编辑。只追问影响首版的未知项；详细技术字段保留在高级编辑。既有本机编辑缓存、版本与 Creator 接续可以复用，但对话式修改界面与状态关联需要实现。
- **可验证验收：** 一句修正能定位到对应蓝图内容，保留原话、假设与版本；明确需要用户决定的点才追问。未保存修改在切换、关闭、失败后可恢复；未确认/供给过期时不能交给 Creator。仅有有界原型脚本时，对不支持的自由输入明确提示，不能假装已理解或保存。

## 失败与风险状态必须进入新版流程

| 状态 | 用户应看到什么 | 实施 / 原型边界 |
|---|---|---|
| 模型未配置 / bootstrap 未完成 | 解释为什么暂不可搜索，保留输入和无需模型的浏览 | 当前已有配置判断和重新读取。不能虚构可用的宿主设置深链。 |
| 来源失败或过期 | 结果顶部说明搜索未完成、仅基于已返回来源，提供重试 | 当前可整体 `recommend()` 重试；没有独立接口就不承诺仅重试某来源。不能转成“市场没有插件”。 |
| 本次没有充分候选 | 明确本次范围与缺口，允许补充需求或共创 | 搜索未完成、覆盖有限、真正功能缺口分别表达。 |
| 工作区为空 / 尚未就绪 | 保留方案，说明需要在宿主建立或选择工作区 | 不假装自动创建、不默认把其他工作区作为材料范围。 |
| 已有草稿 / 附件 | 显示原稿保留、本次未覆盖，提供打开原稿或复制当前方案 | `applied/preserved/blocked` 必须分开；“准备草稿”不等于发送、执行或完成。 |
| Creator 创建/关联保存结果未知 | 显示已知会话与恢复动作，保留原 attempt | 不用再次新建掩盖不确定状态，不能把按钮成功当插件建造完成。 |
| 未保存编辑 / 存储失败 | 清楚显示已保存到哪里、哪些仍只在窗口中，允许恢复 | 编辑缓存不等于服务端版本；确认后才能接续已保存的蓝图。 |
| 原型合成结果 | 显式显示演示数据、模拟接口与未接通能力 | 原型可点击、源码可做、正式已实现、实机通过四种状态分别记录。 |

本报告只形成改造依据。新版原型还需分别做视觉检查、键盘与窄屏检查、失败状态走查；正式实现还需验证宿主、接口、模型和恢复路径，不能沿用旧版验收代替。
