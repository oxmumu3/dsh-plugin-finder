# 单首页、需求驱动动线

依据：用户2026-10-22明确纠正“四个tab很呆板”，指定极简首页、输入即查找、主动推荐同页、结果不合适再引出创作。此明确方向替代0.5导航设计；保留旧方案文档与历史，不再要求用户重复选择设计。

首页只有品牌、次要历史入口与折叠更多；主区是“你想完成什么？”、输入与一个“帮我找方案”主按钮。猜你喜欢与精选插件直接出现在输入下，调整兴趣折叠。无历史正信号不假装猜你喜欢。已有任务只显示小的继续入口，重开不会用旧蓝图抢占首页。

点击查找串行理解+推荐，使用既有服务；模型输入说明在按钮附近。用户可取消、失败可重试、结果可编辑。首页输入独立于活动任务，浏览卡片/返回首页不能覆盖旧编辑。开始新任务前保留草稿并确认reset；严守精确身份与旧历史保护。

匹配结果主线为可用方案→安装/会话；本次有缺口时问“还没有合适的方案，要一起做一个吗？”。搜索失败给重试，不当供给缺口；已有方案也可在次要位置主动定制。进入创作引导不调用模型，先看能力、可信case、首版实践，再点“用我的需求起草”生成蓝图，最后交给官方Creator。所有阶段为同一旅程子页，不增加功能tab。

视觉：以宿主中性底色/文字和单一动作色为准，Vercel式简洁层级；系统字体、标题24–28px、输入高度约110px、轻边框推荐条目，无装饰渐变，无大卡套大卡。历史、草稿、设置按需打开。

本轮交付0.6.0-preview.1本地包，保留0.5和既有两路径证据。当前实现与原生更新均不公开发布，不改全局模型/网络，不操作微信客户端。
