# 发现好插件首版

用户于 2026-10-20 明确批准按已审阅 HTML v2 和供给检索方案开始真实开发。该批准覆盖实施、可安装首版及隔离验证，不重复设计审批。原型：`../../../output/deepseek-ai-pm-2026-10-16/plugin-finder-prototype-v1/`（相对于 Agent 根定位）。

## 产品行为

在 DSH 宿主侧栏增加一个“发现好插件”入口，在独立 main 面板内完成需求理解、真实候选检索、方案确认和会话草稿接续。不替换宿主侧栏、会话、composer 或应用根。

用户主动提交需求才调用宿主已配置模型；先解析目标、材料、产出、硬约束、能力及查询词，允许用户修改；随后在附带的真实索引中检索，再用同一宿主模型给出少量候选与最小方案。推荐必须允许原生够用、单插件、至多两个插件的组合及缺供给。模型仅能引用给定候选 ID，来源、版本、依赖和核验状态由服务端的索引记录提供，模型不得生成安装来源。

模型配置取宿主全局默认，界面明确显示路由摘要，不声称天然等于当前会话选择。不另收模型 Key。未配置、额度不足、返回格式不合法、超时分别报可操作错误，不把关键词结果冒充模型理解。第三方目录文本始终是引用数据，不是执行指令。

索引首批约 10–20 个真实 DSH bundle；固定作者仓库、包版本、提交、兼容声明与文档来源，标明 metadata-only。只读刷新不安装或执行候选代码。不存在的能力不得硬凑。首版不静默启用自定义市场或修改用户 profile。

方案确认后选择实际工作区，调用官方 uiWorkspace.startSession 准备普通文本草稿，保留已有草稿/附件，切回原生会话，由用户发送。安装交宿主插件管理；首版提供精确安装信息和打开管理入口，不能把自制复选框当宿主授权。组合待真实任务回验。

反馈只在用户点击提交后记录到本机插件数据，包含结果状态、候选与简短说明，不自动外发、上传任务或联系作者。可复制脱敏反馈。
