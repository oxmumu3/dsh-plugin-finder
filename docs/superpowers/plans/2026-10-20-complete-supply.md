# 动态完整供给与本机匹配记录

用户已授权原设计范围：接真实插件供给（含 GitHub-only），更新当前 DSH，在原资料库任务复测。最新补充：一期只积累我们自己的需求—方案—插件—反馈记录，不联系作者、不建设创作者后台。

1. 完整动态第三方目录作为元数据主源，保留 format-1 市场和 GitHub topic 补充；覆盖按来源条目说明，不宣称穷尽全网。
2. 仅对匹配候选读取固定 commit 的真实 manifest/README/声明 patch，支持 GitHub monorepo 子目录；不执行仓库或构建。Key 条件在最终候选占位前筛除并补读后续项。
3. 保存并展示来源原始数量、npm/GitHub-only、匹配、已核对、排除、未核对及预算。旧历史继续可读，所有方案与反馈保持精确版本关联。
4. 一期作者反馈使用现有本机任务记录。提供按插件生成的本机反馈草稿；具体需求和反馈由用户填写可分享摘要，避免把完整会话/本地路径自动带出。安装、运行、任务自报分开，不以推荐或会话接续代替首用证明。
5. 回归测试、独立审读、打包并热升级当前 Desktop profile，只替换 Finder，不重启 Host，不更改其他插件或原研究文件。
6. 用原始资料库需求及已记录失败意见再推荐，保留旧版本，读回实际来源覆盖与精确推荐。公开发布安装包和验证证据。
