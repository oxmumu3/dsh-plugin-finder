# 发布前最后一轮收尾

用户目标：结束持续功能迭代，修完影响首次试用的关键问题后推广。当前公开版本 0.3.0-preview.1，基线 255 项测试通过。

## 已检查的实际问题与设计

本轮原生截图 `output/plugin-finder-launch-review-2026-10-21/01-before-plan.png` 显示：历史反馈及完整搜索证据先于答案，方案和接续需要长距离滚动；所选插件精确安装来源又藏在折叠详情内。保留原生工作区、模型、存储和安装权限边界，仅调整信息顺序和安装说明。

方案优先呈现，所选插件安装引导和会话接续紧随。历史版本继续可达，旧反馈、完整搜索统计与作者资料渐进展开。来源异常保留可见提示，重要前提不冒充已验证。给出复制精确来源、在宿主添加/安装/启用、回到侧栏原方案的路径；不增加自动安装或安装状态推断。

公开 repo topics 为空且当前精选池未收录是实际分发缺口。补自有 repo topics 和包关键词，核对真实收录路径。GitHub Release、npm 发布、topic 可发现和精选池收录分别报告，不互相替代。

## 执行与收尾条件

- [ ] Client agent 在 `test/client.test.mjs` 加排序、安装引导和来源异常可见的失败回归，再改 `src/client.js`/`src/client-style.js`，不改 Host API 或历史协议。
- [ ] Root 检查版本、发布入口与安装文字，更新准确的简短宣传口径；不代发公众号、推特或即刻，不许诺全网穷尽或自动安装。
- [ ] 独立审读可复现的启动、模型、存储及遥测阻断；只修有影响的问题，不新增产品系统。
- [ ] 完整测试、构建、包清单和凭据排除检查；通过原生管理器更新当前 DSH，不重启 Host、不代替用户同意，保护旧任务版本与反馈。
- [ ] 原生读回方案优先、安装引导、历史恢复、默认关闭授权；公开 Preview 包并核对匿名下载，冻结版本。

本轮不做：作者门户、自动使用验收、新推荐算法、多平台迁移、付费能力。用户反馈将决定后续迭代。发布验收与外部用户采用结果分开。
