# 发现好插件项目规则

- 对外 GitHub 品牌和项目归属固定为 `oxmumu3`；正式仓库为 https://github.com/oxmumu3/dsh-plugin-finder 。不能把当前 CLI 登录的开发账号当成发布目标。
- 提交精选库、创建 PR、Release、安装入口或宣传链接前，读回 owner、操作身份及精确附件 URL。收录投稿身份同样使用 `oxmumu3`。
- 已发布版本、附件与校验值保持可追溯；账号迁移更新现行入口，不覆盖同版本附件，也不改写历史验收证据。
- 本机已有 DSH 工作区、历史、草稿和反馈不得因发布维护而清除；账号迁移无需重启或重装。
